# Codex

Gravity demos in Python:

1. `gravity_explainer.py` prints a plain-language explanation.
2. `gravity_animation.py` generates an HTML animation that compares a feather falling with a car falling.

## Run text explanation

```bash
python gravity_explainer.py
```

## Build animation page

```bash
python gravity_animation.py
```

Then open `gravity_fall_animation.html` in your browser.
